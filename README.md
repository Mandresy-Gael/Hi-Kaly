# Hi'Kaly

Site web vitrine pour un restaurant gastronomique malgache situé à **Majunga, Madagascar**.

## Fonctionnalités

* Page d'accueil immersive
* Menu gastronomique avec plats, descriptions et prix
* Formulaire de réservation avec validation JavaScript
* Confirmation de réservation côté client
* Présentation de l'histoire et de la philosophie de Hi'Kaly
* Section contact et réseaux sociaux
* Navigation responsive avec menu mobile
* Animations au scroll

## Technologies

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

## Structure

```text
Hi'Kaly/
├── hi'kaly.html

└── hi'kaly.js
```

## Installation

Cloner le repository :

```bash
git clone https://github.com/USERNAME/hi-kaly.git
```

Puis ouvrir `hi'kaly.html` dans un navigateur.

Pour le développement, **Live Server** est recommandé.

## Réservation

Le formulaire permet de renseigner :

* Nom
* Téléphone
* Date
* Nombre de convives
* Service (déjeuner/dîner)
* Heure
* Occasion spéciale

La validation et la confirmation sont actuellement gérées **côté client avec JavaScript**. Aucune donnée de réservation n'est encore enregistrée dans une base de données.
